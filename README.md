# Libertex Skills

Коллекция ИИ-навыков (skills) для работы с торговой платформой **Libertex** через MCP (Model Context Protocol).

Каждый навык — это самодостаточная папка с файлом `SKILL.md`, справочниками и шаблонами, которую можно подключить к ИИ-агенту (Cline / Claude Code).

---

## 📦 Навыки в репозитории

| Навык | Описание | Статус |
|---|---|---|
| [`libertex-trade`](./libertex-trade/) | Планирование и ведение лонг-сделок по трендовым акциям Libertex. Риск 3%, мультипликатор x3, RR 2:1, учёт комиссий и свопов. | ✅ Готов |

## ➕ Как добавить новый навык

1. Создайте папку с именем навыка (kebab-case, например `libertex-portfolio`).
2. Внутри — файл `SKILL.md` с frontmatter:
   ```yaml
   ---
   name: <имя-навыка>
   description: <когда и зачем использовать>
   allowed-tools: [...]
   ---
   ```
3. Добавьте `README.md` с подробным описанием, `references/` для справочников и `assets/` для шаблонов.
4. Допишите строку в таблицу «Навыки в репозитории» выше.
5. Закоммитьте и запушьте.
