# Position Management — ведение открытой позиции

Применяется в **режиме B** (позиция уже открыта). Новая сделка не ищется.

## 1. Что проверять при каждом вызове

1. **Текущая цена** — `get_current_quotes(symbol)`.
2. **Расстояние до SL и TP** — в % от цены и в деньгах с учётом объёма.
3. **Новости против позиции** — `get_latest_news(symbols)` + `get_news_text` на предмет негатива.
4. **Счётчик дней** — сколько календарных дней прошло с даты входа (`journal.md`).
5. **Своп-издержки** — по числу прошедших ночей (`times_applied_by_night`).

## 2. Правила действий

| Ситуация | Действие |
|---|---|
| Цена ≥ TP | Фиксировать прибыль (закрыть) |
| Цена ≤ SL | Закрыть по стопу |
| Прошло **> 10 календарных дней** | Закрыть позицию по рынку (регламент) |
| +1×риск достигнут | Перевести SL в безубыток (по умолчанию) |
| Резкий негатив (новость/обвал) | Досрочное закрытие, даже если SL не достигнут |
| Приближение к SL (< 30% дистанции) | Предупредить пользователя |
| Осталось 1–2 дня до 10-дневного лимита и позиция в небольшом плюсе | Рекомендовать закрытие |

## 3. Чего НЕ делать

- Не открывать вторую позицию, пока открыта первая.
- Не увеличивать риск сверх 3% депозита.
- Не «переносить» стоп в убыточную зону.

## 4. Формат отчёта по позиции

```
Позиция: <тикер>, лонг x3
Вход: <entry> | Текущая цена: <rate> (<±%>)
SL: <SL> (<-X%>) | TP: <TP> (<+Y%>)
Объём: <qty> акций (~$<position_size>), маржа $<margin>
Своп накопленный: $<swap>
Дней в позиции: N / 10
Новости: <кратко>
Рекомендация: [Держать | Закрыть по TP | Закрыть по SL | Закрыть по сроку | Досрочно на негативе]
```

## 5. После закрытия

- Записать в `journal.md`: дата закрытия, цена, P&L (с учётом комиссий и свопов), причина.
- Далее по запросу — запуск **режима A** для выбора следующей акции.
