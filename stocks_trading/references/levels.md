# Levels — правила расчёта входа, Stop Loss и Take Profit

Уровни ставятся **исходя из рыночной ситуации на момент открытия**, а не как фиксированный процент.

## 1. Точка входа (Entry)

Приоритет выбора входа:

1. **У уровня/поддержки:** если цена сейчас у поддержки или пробила и ретестит её — вход по текущей цене (`get_current_quotes.rate`).
2. **На retest пробоя:** вход при возврате к пробитому уровню (по свечам h4/m30).
3. **По тренду:** если цена в импульсе — вход по рынку, но стоп ставится шире (ATR).

Всегда фиксировать `entry` и `timestamp` котировки — цена меняется.

## 2. Stop Loss

Ставится **за уровнем, который отменяет сделку**:

- **Основной вариант:** под ближайший локальный минимум/поддержку на h4/m30 (с небольшим буфером 0.1–0.3 × ATR, чтобы не выбивало шумом).
- **Альтернатива:** `entry − 1.5 × ATR14(D1)`.
- **Выбор:** берём вариант, который даёт **дальний** стоп (устойчивее к шуму), но при этом `sl_dist` такой, что риск остаётся ≤ $207 при рассчитанном объёме.
- Если стоп получается настолько далёким, что объём становится меньше `min_inv` → сделка отклоняется.

```
sl_dist = |entry − SL|
```

## 3. Take Profit

Обязательное правило: **TP = 2 × SL** (RR = 2:1).

```
tp_dist = 2 × sl_dist
TP = entry + tp_dist
```

- Если TP упирается в сильное сопротивление **раньше** расчётной цели — TP ставится перед сопротивлением, но тогда пересчитай SL так, чтобы сохранить RR = 2:1 (или отклони сделку).
- Не «растягивать» TP искусственно ради красивого RR.

## 4. Фильтр реалистичности

- Движение до TP должно быть реалистично за ≤ 10 дней: `tp_dist` не больше, чем ~2.5–3 × ATR(D1) × √(дни) — примерно.
- Если для достижения TP требуется нереалистичный рост — акция отбраковывается.

## 5. Пример

```
entry = 345.09
SL    = 332.00  → sl_dist = 13.09
TP    = 345.09 + 26.18 = 371.27
RR    = 2.0
```

## 6. При ведении позиции

- Перевод SL в безубыток после +1×риска (по умолчанию включён).
- Трейлинг SL по ATR — опция (см. `position-management.md`).
