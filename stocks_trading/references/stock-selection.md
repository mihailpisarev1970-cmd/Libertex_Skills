# Stock Selection — критерии отбора трендовых акций

Отбор строгий: **лучше пропустить день, чем войти в нетрендовую акцию.**

## 1. Вселенная инструментов

- Только `type = stock` из каталога Libertex (`list_instrument_types` → `search_instruments`/`get_instruments`).
- Акция должна быть **реально торгуема** в терминале: `is_market_open = true`, `is_enable_open_buy = true`, `mult_settings.values` содержит 3.
- Не брать ETF, индексы, крипту, металлы — только отдельные акции.

## 2. Тренд-фильтр (ВСЕ условия обязательны)

Запрашивай `get_candles_history`:
- `interval: D1` — минимум 200 свечей (несколько запросов по датам, лимит 100 за раз);
- `interval: h4` — направление среднесрочно;
- `interval: m30` — точка входа.

**Тренд восходящий, если:**
1. `close > SMA200(D1)` **и** `SMA200` растёт (сравнить с SMA200 10–20 дней назад).
2. `EMA20 > EMA50 > EMA200` на D1.
3. Последовательность более высоких максимумов и минимумов на D1 (HH/HL).
4. Рост объёмов на бычьих свечах (подтверждение).
5. Нет явного перегрева: RSI14 (D1) < 80.

Если **хотя бы один** пункт не выполнен → **акция отклонена**.

## 3. Оценка «большого потенциала»

Из прошедших тренд-фильтр ранжируй по:

| Критерий | Как измеряем | Вес |
|---|---|---|
| Запас хода | (Ближайшее сопротивление − entry) / entry | высокий |
| Волатильность | ATR14(D1) / entry — должна быть достаточной для TP за ≤10 дней | высокий |
| Сила тренда | наклон EMA20, расстояние до EMA200 | средний |
| Ликвидность | объём, спред (`spread` из `get_current_quotes`) | средний |
| Новостной катализатор | позитивные новости | средний |

**Правило потенциала:** расстояние до ближайшего сопротивления должно быть **≥ TP-расстояния** (`2 × sl_dist`). Если TP не помещается до сопротивления — либо TP ставится перед сопротивлением (и RR всё равно 2:1 при корректном SL), либо акция отбраковывается.

## 4. Выбор одной акции

- Выбирается **ровно одна** акция — с максимальным потенциалом и минимальным сопротивлением к цели.
- Остальные кандидаты перечисли кратко с причиной отказа (для прозрачности).
- Если ни одна не прошла — вывод: «Сегодня сделки нет», с указанием причин по каждой.

## 5. Частые ошибки (избегать)

- Вход в акцию в боковике (цена между EMA50 и EMA200, «пила»).
- Вход на перегретом росте у сильного сопротивления.
- Игнорирование новостей (earnings, guidance, регуляторика).
- Использование дневных свечей без проверки h4/m30 перед входом.
